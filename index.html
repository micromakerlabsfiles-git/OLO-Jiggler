Welcome to OLO Jiggler

An advanced BLE Mouse Jiggler and daily utility device for your ESP32-C3. Connect via USB Serial to configure settings, select screensaver options, sync time, and control your device.

📖 Quick Start Guide

🤔 What is OLO Jiggler?

  • Mouse Jiggler — keeps computer awake over BLE by moving mouse pointer.
  • Utility Pages — on-screen Daily Tracker, Quotes, Pomodoro, and Stats.
  • OLED Face UI — animated eye display screensaver when idle.
  • Web Controller — manage settings, sync clock and flash firmware over USB.

⚡ System Requirements

  • Google Chrome or Microsoft Edge browser (Web Serial API support).
  • OLOBit ESP32-C3 hardware or compatible board.
  • USB-C cable for configuration; BLE support on host PC for jiggling.

🔌 Step-by-Step Instructions

  1. Plug your OLOBit hardware into your computer using a USB-C data cable.
  2. Click ⚡ Connect via USB Serial above, select your device, and click Connect.
  3. The dashboard will unlock automatically and synchronize the on-device real-time clock (RTC).
  4. Adjust settings in the settings panel, select Jiggle modes, or play retro games on screen!
💡 The Jiggler functions completely standalone once configured. You only need the USB connection to change options, sync time, or flash firmware.
